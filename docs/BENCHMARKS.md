# Benchmarks du moteur de simulation (phase 3, mi-parcours)

> Généré par `npm run bench:engine` — **valeurs dépendantes de la machine**, à reproduire sur la vôtre.

- Date : 2026-10-11 · Node v22.22.0 · Intel(R) Xeon(R) Processor @ 2.10GHz · 4 cœurs · 16093.2 Mo RAM
- Graphe : ville schématique 1800 arêtes, 3044 bâtiments (zone 2800×2100 m) — construction 21 ms ; masque de marche 3159×2537 (7.6 Mo) — rasterisation 40 ms
- Tailles : 5000 / 10000 / 25000 / 50000 / 100000 / 250000 personnes (mode étendu : recherche des limites au-delà de l'objectif de 50 000).
- Protocole : graine fixe, 15 ticks d'échauffement puis 100 ticks mesurés (pas de 100 ms de jeu), un seul fil, sans rendu.
- Niveaux : **N2** dynamique individuelle (rappel + bruit + rejet des bâtiments) · **N1** positions = cibles analytiques · **N0** rien n'est mis à jour (positions évaluées à la demande) · **mixte** : foyer d'attention de 250 m (N2 près, N1/N0 loin).
- Mémoire : « tableaux d'individus » = taille exacte des tableaux typés (positions, cibles, graines, créneaux, disposition statique) ; « tas JS observé » = variation de `heapUsed + arrayBuffers` autour de la création (indicatif, bruité par le ramasse-miettes). Le masque de marche (grille d'occupation) est compté à part.
- « Vitesse max soutenable » = multiple de vitesse de jeu pour lequel le moteur occuperait ≤ 50 % du temps réel (10 ticks de jeu par seconde à 1×) : `50 / tick_moyen_ms`.
